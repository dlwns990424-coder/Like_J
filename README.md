# TripJ

여행지 탐색부터 일정, 숙소, 예산 및 지출 관리까지  
여행 계획의 전 과정을 한 곳에서 관리할 수 있는 모바일 중심 여행 플래너 웹앱입니다.

Google Maps와 Google Places API를 활용하여 도시와 장소를 검색하고, 관심 있는 장소를 저장해 실제 여행 일정으로 구성할 수 있도록 제작했습니다.

---

## 프로젝트 소개

여행을 준비할 때 여행지 검색, 방문 장소 저장, 일정 관리, 숙소 관리, 예산 및 지출 기록 등을 각각 다른 서비스에서 관리해야 하는 불편함에서 시작한 프로젝트입니다.

TripJ는 하나의 여행을 중심으로 필요한 정보를 연결하여

**여행 생성 → 장소 탐색 → 관심 장소 저장 → 일정 구성 → 숙소 관리 → 지출 관리**

까지 하나의 서비스에서 관리할 수 있도록 구현했습니다.

## 주요 기능

### 여행 생성 및 관리

- Google Places API를 이용한 도시 및 국가 검색
- 여행 시작일 / 종료일 선택
- 사용자별 여행 저장
- 여행 제목 수정
- 여행 기간 수정
- 여행 삭제
- 여행 기간 변경 시 범위를 벗어난 일정 데이터 처리

### 지도 및 장소 검색

- Google Maps 기반 지도
- Google Places 기반 장소 검색
- 현재 위치 확인
- 검색한 장소 위치로 지도 이동
- 장소 상세 정보 확인
- 주소, 평점, 영업시간, 전화번호, 웹사이트 정보 제공
- 관심 장소 추가
- 검색한 장소를 일정에 추가
- 검색한 장소를 숙소로 등록

### 관심 장소 관리

- 여행별 관심 장소 저장
- 관심 장소 목록 확인
- 관심 장소 검색
- 관심 장소 선택 삭제
- 관심 장소 전체 삭제
- 관심 장소에서 날짜를 선택해 일정으로 추가

### 일정 관리

- 여행 기간을 기준으로 DAY 자동 생성
- DAY별 일정 관리
- 장소 일정 추가
- 일정 시간 설정 및 수정
- 일정별 메모 작성 및 수정
- 시간순 / 추가순 정렬
- 일정 선택 삭제
- 일정 전체 삭제
- 일정이 없는 날짜의 Empty UI 제공

### 숙소 관리

- 관심 장소 또는 지도에서 숙소 등록
- 체크인 / 체크아웃 기간 설정
- 숙박 기간에 맞춰 일정에 숙소 표시
- 등록된 숙소 삭제

### 메모 관리

- 여행 전체 메모 작성 및 수정
- 날짜별 일정 메모 작성 및 수정
- 장소별 메모 작성 및 수정

### 예산 및 지출 관리

- 여행 국가에 따른 화폐 단위 적용
- 여행 전체 예산 설정 및 수정
- 총 지출 금액 자동 계산
- 남은 예산 자동 계산
- 예산 초과 시 남은 예산 강조 표시
- 특정 일정과 연결된 지출 등록
- 일정과 관계없는 기타 지출 등록
- 지출 금액 및 메모 수정

### 마이페이지

- 닉네임 수정
- 사용자별 여행 목록 확인
- 여행 목록 정렬
- 여행 선택 삭제
- 여행 전체 삭제

## 주요 구현 포인트

### 1. 여행 중심의 데이터 구조

사용자와 여행을 기준으로 관심 장소, 일정, 숙소, 지출 데이터를 연결했습니다.

```text
User
 └── Trip
      ├── Favorite Places
      ├── Schedules
      │    ├── Schedule Memo
      │    └── Accommodation
      └── Expenses
```

`userId`, `tripId`, `scheduleId`, `date` 등을 활용하여 각 데이터가 특정 사용자와 여행에 연결되도록 구성했습니다.

---

### 2. Google Maps와 여행 일정 연결

단순한 장소 검색에서 끝나는 것이 아니라 검색한 장소를 실제 여행 계획에 활용할 수 있도록 구현했습니다.

```text
Google Maps 장소 검색
        ↓
    장소 상세 확인
        ↓
    관심 장소 저장
        ↓
     일정에 추가
        ↓
    여행 일정 관리
```

지도에서 발견한 장소를 관심 장소로 저장하거나 바로 일정 및 숙소로 등록할 수 있도록 구성하여 장소 탐색과 여행 계획이 자연스럽게 이어지도록 했습니다.

---

### 3. 여행 기간 기반 DAY 자동 생성

여행의 시작일과 종료일을 기준으로 전체 날짜를 계산하여 DAY 탭을 자동으로 생성합니다.

```text
2026-08-20 ~ 2026-08-23

DAY 1  08.20
DAY 2  08.21
DAY 3  08.22
DAY 4  08.23
```

각 날짜마다 별도의 일정, 메모, 숙소 정보를 관리할 수 있으며 여행 기간을 수정할 경우 새로운 여행 기간을 벗어나는 기존 데이터도 함께 처리할 수 있도록 구현했습니다.

---

### 4. 일정과 지출 데이터 연결

지출을 단순한 금액 목록으로 관리하지 않고 실제 여행 일정과 연결할 수 있도록 구현했습니다.

```text
DAY 2
 └── 오사카성
      ├── 일정 시간
      ├── 일정 메모
      └── 지출
```

특정 일정에서 발생한 지출은 해당 일정과 연결하여 기록할 수 있으며 일정과 관계없는 비용은 `기타 지출`로 별도 관리할 수 있습니다.

---

### 5. 기능별 컴포넌트 분리

기능이 증가하면서 하나의 페이지에서 모든 UI와 로직을 처리하지 않고 역할에 따라 컴포넌트를 분리했습니다.

```text
TripDetail
 │
 ├── TripHero
 ├── TripDetailTabs
 │
 ├── TripPrepare
 │    ├── TripMemo
 │    └── FavoritePlaces
 │
 ├── TripSchedule
 │    ├── ScheduleDateTabs
 │    ├── ScheduleTimeline
 │    ├── SchedulePlaceCard
 │    ├── ScheduleMemo
 │    └── ScheduleAccommodation
 │
 └── TripExpense
      ├── ExpenseBudgetCard
      ├── ExpenseList
      ├── BudgetModal
      └── ExpenseRecordModal
```

Header, Bottom Navigation, Confirm Modal, Toast 등의 UI도 공통 컴포넌트로 분리하여 여러 화면에서 재사용할 수 있도록 구성했습니다.

---

### 6. 모바일 중심 UI

모바일 환경을 중심으로 UI를 설계했으며 Safe Area를 고려하여 상단 및 하단 영역이 모바일 브라우저 UI와 겹치지 않도록 구성했습니다.

스크롤 영역, 하단 네비게이션, 모달, Bottom Sheet 등의 UI도 모바일 사용성을 중심으로 구현했습니다.

## 프로젝트 목표

TripJ는 여행 계획에 필요한 기능을 단순히 모아놓는 것이 아니라 각 기능이 하나의 여행 데이터를 중심으로 자연스럽게 연결되는 것을 목표로 제작했습니다.

지도에서 발견한 장소를 관심 장소로 저장하고, 저장한 장소를 실제 여행 일정으로 구성하며, 일정에 숙소와 지출 정보를 연결함으로써 **여행을 계획하는 전체 과정을 하나의 서비스 안에서 관리할 수 있는 경험을 제공하는 것**을 목표로 합니다.
